## 1. Project Scope

- **Workstream B Ownership:** AI perception pipeline, procedure intelligence, deterministic FSM validation, action/object vocabularies, temporal confirmation, uncertainty handling, recovery logic, HMR/3D research extension, and telemetry evaluation.
- **Relationship to Workstream A:** Workstream A owns system runtime (camera ingestion, MJPEG/RTSP streaming, recording, desktop GUI, voice alert worker, diagnostics). Workstream B consumes frame sources from A and supplies validated procedure results back to A via a frozen public interface.
- **Relationship to Part 1 (Colab):** 
  - **PART 1 (Google Colab):** Dataset creation, model training, feature extractor training, model quantization/export.
  - **PART 2 (Local Edge Runtime):** Desktop application, backend orchestrator, deterministic FSM sequence validator, hardware acceleration fallback, and model integration.
  - **Current Status:** The early exported Part-1 model contains only binary classes (`catch` / `not-catch`). Part 1 is currently being modified/retrained in Colab. Therefore, Part-1 model integration into Part 2 is **intentionally NOT active** at this stage. Part 2 develops model-independent procedure intelligence and verification tools.

## 5. Current AI / Model Situation

### Part 1 (Colab)
- **Current Baseline Dataset:** HMDB51 (`training/data/raw/hmdb51_sta/`) — the active Part-1 training dataset source.
- **Current Baseline Model Classes:** Binary classifier: `catch`, `not-catch`.

- **Future Dataset Path:** EXP-001-specific labeled clips (defined in `docs/workstream-b-dataset-protocol.md`) are a future collection requirement for direct 5-action procedure recognition. Additional external/custom datasets may be introduced in later SIH stages.

- **Approach:** Model-independent procedure & FSM infrastructure.
- **Current Dependency on Part 1:** None — Part 2 develops independently from the changing Part-1 model.
